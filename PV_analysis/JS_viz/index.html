Solar dashboards

Mirrors core Streamlit-style views (Daily, Difference) using PV_analysis/data_for_viz/*.csv, plus Library (PVLib) and 7-day forecast (forecast_7d_combined_library.csv from the XGBoost + Azure script). The Difference tab adds daylight-only difference plots plus a full-width health ratio (H) chart. Serving (recommended): from the repo, run python PV_analysis/serve_js_dashboard.py — it always uses the PV_analysis folder as the web root, then open http://127.0.0.1:8080/JS_viz/. A 404 on that link almost always means the server was started in the wrong directory: e.g. if you run python -m http.server from the repo root, /JS_viz/ does not exist (you would need /PV_analysis/JS_viz/ instead). The helper script avoids that mismatch.
