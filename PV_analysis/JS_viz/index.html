Solar dashboards

Mirrors the Streamlit tabs (Difference, Daily, Series, Fleet) using PV_analysis/data_for_viz/*.csv, plus Library (PVLib) and 7-day forecast (forecast_7d_combined_library.csv from the XGBoost + Azure script). The Difference tab includes a full-width health ratio (H) chart plus forecast charts; forecast needs a Real baseline (legacy_expected_kwh and/or loadable data_pvlib/expected_power_pvlib_cleaned_v2.csv). Serving (recommended): from the repo, run python PV_analysis/serve_js_dashboard.py — it always uses the PV_analysis folder as the web root, then open http://127.0.0.1:8080/JS_viz/. A 404 on that link almost always means the server was started in the wrong directory: e.g. if you run python -m http.server from the repo root, /JS_viz/ does not exist (you would need /PV_analysis/JS_viz/ instead). The helper script avoids that mismatch.
